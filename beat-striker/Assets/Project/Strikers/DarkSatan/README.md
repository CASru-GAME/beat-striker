# 魔王 3Dモデル

キャラクター選択画面の右端にある立ち絵（`Assets/Project/Screen/CharacterSelect/a.png`）を参考に、Blender 5.1で制作したデフォルメキャラクターです。赤い肌と角、黒いボブヘア、金縁のロングコート、腰のチェーン、マイクを立体化しています。画像に写っていない背面は、前面のデザインに合わせて補っています。

## ファイル

- `DemonKing.blend`：編集用のBlenderシーン。パーツ、マテリアル、骨、カメラ、照明を含みます。参照画像はプロジェクト内の画像を相対パスで参照し、初期状態では非表示です。
- `DemonKing.fbx`：骨とマテリアルを含むニュートラルポーズのモデル。
- `DemonKing.glb`：骨とマテリアルを含むニュートラルポーズのモデル。
- `DemonKing_preview.png`：マイクを持つポーズのレンダリング。
- `DemonKing_front.png`、`DemonKing_back.png`：ニュートラルポーズの正面・背面。
- `create_demon_king.py`：モデルと書き出しファイルの生成スクリプト。

## 編集

`.blend` を開くと、フレーム40のポーズを表示します。タイムラインをフレーム1に移すとニュートラルポーズになります。アウトライナーの `DemonKing_Rig` を選んでポーズモードに切り替えると骨を操作できます。マイクも手の骨に追従します。FBXとGLBには、この確認用ポーズアニメーションは含めていません。

キャラクターの高さは角を含めて約3.47 Blender単位です。全身は約150の独立メッシュからなり、ウェイトは主にパーツ単位で割り当てています。大きく動かす場合は関節やコートのウェイト・干渉調整が必要です。ゲームでは `DemonKing.prefab` の表示モデルとして使用します。Humanoid の骨割り当てを設定し、魔王専用に複製した状態スクリプトと戦士の Humanoid モーションを使用します。描画負荷を抑えるためのメッシュ統合は行っていません。

## 通常攻撃

`DemonKing.prefab` の `States/DemonMeleeAttackState` が通常攻撃を制御します。連続入力で突進パンチ（0.28秒）、跳び上がり打撃（0.34秒）、一回転の蹴り（0.38秒）、後方宙返りキック（0.40秒）の順に切り替わります。動作中は次の攻撃を1回分受け付け、待機へ戻ってからも設定された受付時間内ならコンボが続きます。被弾や別の行動で中断すると最初の技に戻ります。展開済みの弾丸がある場合は、その発射が優先されます。

各技のクリップは `States/Attack/DemonJab.anim`、`DemonRisingPunch.anim`、`DemonSpinKick.anim`、`DemonBackflipKick.anim` に保存しています。拳・足の発光、闇の火花、光跡、接触判定はモデル内の `Left Fist Dark Energy`、`Right Fist Dark Energy`、`Right Kick Dark Energy` で編集できます。打撃の閃光・衝撃波・効果音は `Effects/Melee` にまとめています。攻撃時間、判定の開始・終了、踏み込み、ジャンプの高さ、威力、吹き飛ばし速度と上向き成分、命中演出の大きさ、コンボ受付時間はプレハブのインスペクタで調整できます。

踏み込みは `StepSpeed` の速度を `StepDuration` の間維持し、`StepBrakeDuration` をかけて減速します。相手との前後方向の距離が `stepStopDistance` に達すると止まります。接地中にジャンプ技を開始すると、`JumpHeight` と攻撃時間に合わせた放物線の速度を Rigidbody に適用します。空中から開始した技は元の上下速度を維持します。

命中判定は拳・足の半径と前方の `energyReach` を含むカプセルを、前フレームから現在の姿勢まで走査します。判定時間をまたぐフレームでも走査し、各技につき1回だけ命中します。命中時は `HitStatus` を通してダメージとノックバックを相手へ渡し、白い閃光、紫の衝撃波、火花、小さな爆発と画面揺れを発生させます。

## 方向つき通常攻撃と必殺技

上方向＋通常攻撃で `DemonJumpUppercutState`、下方向＋通常攻撃で `DemonHeelDropState` に分岐します。どちらも0.4秒で、地上・空中から使用できます。上攻撃は跳び上がりながら右拳を突き上げ、下攻撃は地上なら小さく跳んでから右脚を振り下ろし急降下します。展開済みの音符弾がある場合は発射を優先します。

専用クリップは `States/Attack/DemonJumpUppercut.anim`、`DemonHeelDrop.anim` と、巨大化の構え・蹴り出し・走行・制動の4クリップです。専用リグの骨トラックを保存し、姿勢と足先の位置を保持します。AnimationPlayerは専用クリップの再生中だけ骨トラックを直接評価し、終了後のHumanoidクリップで元のアバターへ戻します。ジャンプと急降下の移動はRigidbodyで制御します。方向技の時間、移動速度、判定時間、威力は各状態のインスペクタで調整できます。

必殺技は空中で発動した場合、重力で着地するまで待ちます。着地後、1.25秒のアテンション中に2.5倍へ巨大化し、腰を落として前後に足を開いたクラウチングスタートの構えを取ります。カメラが引き始めると相手の操作を再開し、同時に0.16秒の蹴り出しを開始し、前傾姿勢で腕と脚を交互に振る0.28秒ループの全力疾走へ移ります。突進は0.72秒、制動・縮小は0.32秒です。突進方向は開始時の相手の位置で固定し、命中は1回までです。命中時は70ダメージと進行方向の斜め上60度へのノックバックを与え、接触位置に大きな爆発と爆発音を発生させます。被弾などで中断されても大きさ、重力、衝突検出設定、演出を復元します。魔力の膜、上昇する炎、速度の光跡、発進時の衝撃波は表示モデルの子オブジェクトとして編集できます。

カメラは巨大化に合わせたアテンション距離を受け取り、突進終了付近まで必要な引きの距離を確保します。高い跳躍では縦方向の余白と追従速度を増やします。BattleプレハブのStageCameraで各値を調整できます。

Unityの `Tools/Strikers/Author Demon Directional And Rush Techniques` で専用クリップとプレハブ参照を再生成できます。`Preview Demon Techniques` は一時ディレクトリにポーズ比較画像を出力します。`Review Demon In Playing Battle` はラウンド開始後のバトルを魔王対戦士へ再配置し、通常攻撃・方向技・必殺技・中断を操作して、一時ディレクトリへ連続画像と移動・HPの計測値を保存します。通常の対戦を中断する確認用メニューです。

## モデルの再生成

リポジトリのルートから実行します。`blender` コマンドがPATHにない場合は、利用するBlenderの実行ファイルを指定してください。

```powershell
blender --background --factory-startup --python-exit-code 13 --python 'beat-striker\Assets\Project\Strikers\DarkSatan\create_demon_king.py'
```
